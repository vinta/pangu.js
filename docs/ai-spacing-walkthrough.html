01 / The execution boundary

AI spacing walkthrough

The content script owns the page text. The service worker owns model sessions. AI spacing has a module in each, connected by a request and its reply.

AI spacing spans both sides. Calls inside a context are ordinary function calls. Only sentences and labels cross the message boundary; DOM nodes stay with the content script.

How does the content script start?

In automatic mode, the worker registers the content script for page loads; the content script checks the URL policy. In manual mode, the popup injects it if needed and sends MANUAL_SPACING using chrome.tabs.sendMessage().

The content script connects the AI callback only if is_ai_spacing_enabled is true. The worker's classification handler does not recheck that setting.

02 / Content script

Rules first. Meaning second.

Pangu finishes a batch of ordinary spacing, then gives AI spacing each node's original and settled text. “Settled” means the rules are done; an AI correction may follow.

01 → ORIGINAL

Read the page

氣溫是-5度

The original text tells us the author put the minus sign directly against the number.

02 → ORDINARY RULES

Insert spacing

氣溫是 - 5 度

The rules insert a space after the hyphen. The hyphen-digit shape flags that gap for classification.

03 → AI QUESTION

Is this a negative number?

kind: hyphen-digit

The content module gathers sentence context and the symbol's position. The worker only needs these values.

OUTBOUND → content script to worker

{
  "type": "CLASSIFY_CANDIDATES",
  "kind": "hyphen-digit",
  "candidates": [
    { "sentence": "氣溫是-5度", "at": 3 }
  ]
}

at is the symbol's index within the sentence. No DOM reference crosses this boundary.

INBOUND ← worker to content script

{
  "ok": true,
  "candidateLabels": [
    "signed-number"
  ]
}

Illustrative model answer. Labels match the candidate array by index. The model's actual choice can vary.

Which shapes ask the model?

hyphen-digit: a CJK character followed by a tight - and digit, where the rules inserted a gap after the hyphen. signed-number removes that gap.

digit-plus: a digit followed by + and CJK text, where the rules inserted a gap after the plus. conjunction adds a gap before it: Switch 2+ 瑪利歐 → Switch 2 + 瑪利歐. The current prompt accepts only context with a single plus.

Other labels leave the rules' output in place. Shapes with candidates send separate requests concurrently.

03 / Service worker

A label comes back, not a rewrite.

The worker selects the shape's prompt, gets its base model session, and classifies candidates in order. A cached answer can skip inference.

  1. 01 → ROUTEChoose the prompt

    kind selects hyphen-digit or digit-plus. Each has its own system prompt and allowed labels.

  2. 02 → REUSECheck the cache

    Reuse the shape's base session and any answer already stored for the generated question, including work still in progress.

  3. 03 → INFER ON A MISSClone → prompt → destroy

    A temporary session clone answers one question with a constrained label. The clone is destroyed after the prompt.

  4. 04 → RESPONDValidate and return

    Parse and validate the answer. Return labels in request order, with null for failed or invalid individual answers.

Warm-up: the same request with an empty array

Before ordinary spacing starts, the content module scans page text once for potential shapes and sends candidates: [] for each relevant shape. That creates or reuses the base session without prompting a candidate.

The model must already be available. This path does not start a model download. The content script ignores warm-up replies; a warm-up failure alone does not set its AI failure flag.

Cache lifetime and concurrency

Session and answer caches live in worker memory and disappear when the worker stops. Failed session creation and null answers are removed from their caches.

Candidates run sequentially inside each request. Separate requests can overlap; there is no global JavaScript queue. Matching requests can share pending work.

04 / Back to the page

Apply the fix only if the text still matches.

The content module turns labels into exact edits and combines all edits for a node into one late fix. Pangu checks the node again when the scheduled write runs.

Content-script context

Guard the DOM write

applyLateFixes(fixes)
  for each fix
    if node is detached, changed, or ignored
      skip
    write fix.data
    remember this AI-fixed text

Expected: 氣溫是 - 5 度
Write: 氣溫是 -5 度

The rules preserve this correction while the node still contains pangu's last written text.
The page changes while AI is thinking

If the page replaces 氣溫是 - 5 度 with 氣溫是 8 度, the stored snapshot no longer matches. The late fix is skipped, so an old model answer cannot overwrite the new temperature.

One candidate returns null or unsure

That candidate produces no edit. Other successful candidates can still be applied, and AI spacing remains available for later batches.

A classification request returns ok: false

A worker communication or model setup failure disables future AI batches for this page. Ordinary spacing continues. Work already in flight may still complete.
