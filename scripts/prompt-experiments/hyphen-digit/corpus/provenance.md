Each case records its URL, retrieval date, exact source text node, target offset, annotation rationale, and relevant HTML fragment. HTML entities are decoded in `original_excerpt`; author whitespace is preserved. Search results were discovery aids. Every selected excerpt was checked in fetched source HTML. Navigate's HTML was also checked against the opened source page after the local certificate chain prevented a normal curl fetch.

`source_html` preserves source element bytes where practical. Large PTT containers retain the original parent opening tag and target text node, with unrelated siblings beyond preserved line breaks omitted. The quoted accounting line retains its `f6` span. This avoids copying page metadata into the experiment.

PTT's [source stylesheet](https://images.ptt.cc/bbs/v2.27/bbs-base.css) sets `#main-content` to `white-space: pre-wrap`. That rule is included in each PTT case's `source_css`. Relevant ancestor display and whitespace were verified on every live source page. The supplier breadcrumb uses flex layout, making its target span a block; its fixture includes that rule. Every `input` and `at` now comes from production `readSentence()` and `hyphenDigit.find()` in Chrome Beta. Captured fragments reproduce the relevant block/inline context; unrelated page behavior and later site changes are outside this snapshot.

The source set is small and clustered. XQ supplies several return examples; Blocktempo supplies all article-number cases; the 2 Taoyuan instructions share one page. PTT occurs in both roles on different boards and pages. Both roles contain numbered product series from different suppliers. These checks test transfer across the selected pages, not arbitrary publishers or domains.

No defensible real `unsure` case was found. Real negative temperature, money, percentages, course/article/product numbers, filename dates, and age ranges are covered. No model inference was performed during collection. Use only verified real text in future examples, diagnostics, and evaluations.
